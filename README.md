# Odin Recipes

The Odin Project kapsamında geliştirdiğim ilk HTML ve Git projesidir. Bu projede temel HTML etiketlerini, sayfa yapılarını, bağlantı (link) yönetimini ve klasör düzenini pratik ettim.

## Proje Icerigi
Bu web sitesi, basit ve lezzetli yemek tariflerini içeren birkaç sayfadan oluşmaktadır:
* Ana sayfa üzerinden farklı tariflere yönlendirmeler
* Malzeme listeleri (Sırasız liste - `<ul>`)
* Hazırlanış adımları (Sıralı liste - `<ol>`)
* Tariflere ait görseller (`images/` klasörü altında)

## Kullanilan Teknolojiler
* HTML5 - Sayfa yapısı ve içerik için
* Git & GitHub - Sürüm kontrolü ve proje yönetimi için

## Bu Projede Ne Ögrendim?
* HTML sayfa yapısını (`<head>`, `<body>`) doğru kurmayı.
* Görselleri yerel klasörlerden (`images/`) çekmeyi ve doğru yollarla (path) bağlamayı.
* Git kriz anlarını yönetmeyi, bozulan `.git` klasörlerini ayağa kaldırmayı ve SSH bağlantısı kurmayı.
